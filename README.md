# Repo Nest Version Control System

A GitHub-inspired application that replicates basic Git commands and provides user authentication and repository management functionality.

Features
* Git Commands Replication: Initialize repositories, add files, commit changes, push, and pull using a terminal-based interface.
* User Authentication: Sign up and log in using Node.js, Express.js API
* CRUD Operations: Create, read, update, and delete data.
* Frontend: Interactive user interface built with React.js and CSS.
* Backend API: APIs developed using Node.js and Express.js.

Tech Stack
* Frontend: React.js, CSS
* Backend: Node.js, Express.js
* Database: MongoDB
